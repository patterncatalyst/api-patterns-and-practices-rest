This site's chapter arc, pattern coverage, and level of rigor draw on a small
set of books on REST and API design. They're reference works, not sources —
no text or code from any of them is reproduced here. If a topic in this site
is useful to you, these are where to go deeper.

| Title | Author(s) | Publisher | Year | Focus |
|---|---|---|---|---|
| *RESTful Web API Patterns & Practices Cookbook* | Mike Amundsen | O'Reilly | 2022 | Hypermedia & REST patterns |
| *API Design Patterns* | JJ Geewax | Manning | 2021 | Resource & operation design patterns |
| *Mastering API Architecture* | James Gough, Daniel Bryant, Matthew Auburn | O'Reilly | 2022 | Gateways, testing, evolution, security |
| *Learning API Styles* | Dynowski | — | — | Comparing REST/gRPC/GraphQL/etc. styles |
| *The Design of Web APIs*, 2nd ed. | Arnaud Lauret | Manning | 2024 | API design process & developer experience |

These titles inform this site's coverage and rigor only — nothing in these
chapters or the runnable examples copies text or code from them.
