This site's chapter arc, pattern coverage, and level of rigor draw on a small
set of books on REST and API design. They're reference works, not sources:
no text or code from any of them is reproduced here. If a topic in this site
is useful to you, these are where to go deeper.

| Title | Author(s) | Publisher | Year | Focus |
|---|---|---|---|---|
| [*RESTful Web API Patterns & Practices Cookbook*](https://www.oreilly.com/library/view/restful-web-api/9781098106737/) | Mike Amundsen | O'Reilly | 2022 | Hypermedia & REST patterns |
| [*API Design Patterns*](https://www.manning.com/books/api-design-patterns) | JJ Geewax | Manning | 2021 | Resource & operation design patterns |
| [*Mastering API Architecture*](https://www.oreilly.com/library/view/mastering-api-architecture/9781492090625/) | James Gough, Daniel Bryant, Matthew Auburn | O'Reilly | 2022 | Gateways, testing, evolution, security |
| [*Learning API Styles*](https://www.oreilly.com/library/view/learning-api-styles/9781098153984/) | Lukasz Dynowski, Marcin Dulak | O'Reilly | 2025 | Comparing REST/gRPC/GraphQL/etc. styles |
| [*The Design of Web APIs*, 2nd ed.](https://www.manning.com/books/the-design-of-web-apis-second-edition) | Arnaud Lauret | Manning | 2024 | API design process & developer experience |

These titles inform this site's coverage and rigor only: nothing in these
chapters or the runnable examples copies text or code from them.
