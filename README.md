# API Patterns and Practices: REST

A chapter-based Jekyll tutorial and conference deck on designing **REST APIs** well,
with runnable examples in **Quarkus** and **Python/FastAPI**, in the `lgtm` house style.

First of four standalone per-style sites split out of the *Cloud Native APIs* project
(REST → gRPC → GraphQL → WebSockets). Quarkus + Python only.

- **Domain:** the canonical shipping / cargo domain used across patterncatalyst material.
- **Runtime tiers:** Docker Compose → minikube (Kubernetes) → CRC (OpenShift Local).
- **Contract-first:** OpenAPI 3.1 is the source of truth; implementations are validated against it.
- **Licence:** MIT (prose and code).
