What this site is

A chapter-based, hands-on path to designing REST APIs well, built around a single OpenAPI 3.1 contract for a shipping and cargo booking domain. Every hands-on chapter ships the same example in both Quarkus and Python/FastAPI against that one contract, and CI validates both stacks against it: a response that violates the contract fails the build. You work through resource design, HTTP semantics, pagination, async operations, HATEOAS, versioning, streaming and large payloads, then tie the contract to its event side with AsyncAPI, CloudEvents and Arazzo. It assumes you can read Java and Python; it is not a tutorial in either language. All container images are UBI-based, and the stack runs on Docker Compose, minikube, and OpenShift Local.
